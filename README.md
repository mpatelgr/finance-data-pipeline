# Finance Data Pipeline

An end-to-end data pipeline for ingesting, cleaning, storing, and analyzing financial time-series data.

## Roadmap
- SQL-based data storage and querying
- Reproducible environments
- Automated testing
- Cloud storage integration

## Project Structure
    data/           raw and processed data files
    notebooks/      exploratory analysis and prototyping
    src/            pipeline scripts and reusable functions

## Getting Started
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run the pipeline: `python src/main.py`
